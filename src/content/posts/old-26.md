1. **문제 개요**

플랫폼 : [webhacking.kr](http://webhacking.kr)

난이도 : score 10

핵심 주제 : php 엔진의 인코딩 및 디코딩 매커니즘 이해

2. **문제 분석**

문제 페이지에 접속하면 별도의 입력문제 페이지에 접속하면 별도의 입력 폼`<form>`)이나 쿠키(Cookie) 데이터 없이 하단에 `view-source` 링크만 존재한다.

확인한 PHP 소스 코드의 핵심 로직은 다음과 같다. 

```php
<?php
  if(preg_match("/admin/",$_GET['id'])) { echo"no!"; exit(); }
  $_GET['id'] = urldecode($_GET['id']);
  if($_GET['id'] == "admin"){
    solve(26);
  }
?>
```

코드의 실행 흐름과 취약점 발생 원인을 단계별로 분석하면 다음과 같다.

- **입력 벡터 파악:** 화면상에 입력 폼이나 변조할 쿠키는 없지만, PHP의 슈퍼글로벌 변수인 `$_GET['id']`를 통해 클라이언트로부터 URL 쿼리 스트링(`?id=값`) 형태의 GET 파라미터를 입력받고 있다.
- **1차 필터링 (**`preg_match`**):**
  - `if(preg_match("/admin/",$_GET['id']))` 구문을 통해 입력받은 `id` 파라미터 값에 `"admin"`이라는 문자열이 포함되어 있는지 정규표현식으로 검증한다.
  - 만약 `"admin"` 문자열이 탐지되면 즉시 `"no!"`를 출력하고 `exit()`를 호출하여 스크립트 실행을 강제로 종료한다.
- **명시적 URL 디코딩 (**`urldecode`**):**
  - 1차 정규식 필터링을 무사히 통과한 `$_GET['id']` 값에 대해 `urldecode($_GET['id'])` 함수를 호출하여 **수동으로 URL 디코딩을 한 번 더 수행**한 뒤 변수에 재할당한다.
- **최종 해결 조건 (**`solve(26)`**):**
  - `urldecode()`를 거친 최종 `$_GET['id']` 값이 `"admin"`과 일치할 경우 `solve(26)` 함수가 실행되며 문제가 해결된다.

3. 풀이 과정

공격 페이로드를 생성하기 위해 웹 기반 데이터 변환 도구인 **CyberChef**를 활용하였다.

![](/images/wehacking-kr/old26/mwa7xfb9-4bl5zmmg.png)

- **1차 강제 인코딩 (**`To Hex`**):**
  - CyberChef의 Recipe에 `To Hex` 블록을 추가하고, 구분자 옵션인 `Delimiter`**를** `Percent`**로 설정**한다.
  - Input 창에 `admin`을 입력하면 모든 알파벳이 강제로 Hex 값으로 변환되며 앞에 `%`가 붙은 1차 인코딩 결과물이 생성된다.
  - **1차 변환 결과:** `%61%64%6d%69%6e`
- **2차 URL 인코딩 (**`URL Encode`**):**
  - `To Hex` 블록 바로 아래에 `URL Encode` 블록을 연결한다.
  - 1차 변환 결과물에 포함된 `%` 기호는 특수문자(ASCII Hex: `0x25`)에 해당하므로, `URL Encode` 블록을 거치면서 모든 `%` 기호가 `%25`로 한 번 더 인코딩된다.
  - **2차 변환 결과 (최종 페이로드):** `%2561%2564%256d%2569%256e`

인코딩 페이로드를 브라우저 수소창 쿼리 스트링`?id=`)에 삽입하여 요청을 전송하면

문제를 해결할 수 있다. 


| 단계 | 실행 주체 / 코드 | `$_GET['id']` 값 | 비고 |
| ------------- | ---------------------------- | --------------------------- | ------------------------------- |
| **1.패킷전송** | 클라이언트 (Browser) | `%2561%2564%256d%2569%256e` | Double URL Encoding 상태 |
| **2.1차 디코딩**    | PHP 엔진 (Auto) | `%61%64%6d%69%6e` | `%25`가 `%`로 1회 디코딩됨 |
| **3.필터링** | `preg_match("/admin/", ...)` | `%61%64%6d%69%6e` | `"admin"`이 없으므로 **우회 성공** |
| **4.2차 디코딩** | `urldecode($_GET['id'])` | `admin` | `%61...`이 `admin`으로 복원됨 |
| **5.조건 통과** | `$_GET['id'] == "admin"` | `admin` | 조건 참(True) → `**solve(26)` 호출** |
